# Matrix EEA

`matrix_eea.hpp` accumulates exact Euclidean transition matrices. It demonstrates the algebra in Part 1; it does not estimate quotients and is not a Lehmer or half-GCD implementation. Signed 64-bit intermediate overflow is not guarded.
